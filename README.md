# Мета — сайт и VK Mini App

Главная https://metapsy.online/ содержит полную версию приложения «Мета»: видео, статьи, информацию о проекте и читалку книги.

Та же сборка доступна по /miniapp/ для VK app54881370. При обновлении переносите проверенную сборку vk-mini-app/dist/ в обе директории: корень и miniapp/. Сохраняйте CNAME, .git и README.md. Не удаляйте miniapp/ при синхронизации корня.

GitHub Pages публикует корень main. Закладки и заметки хранятся в браузере пользователя. Кэши service worker разделены по scope.

Предыдущая главная сохранена в истории Git до этой замены и локально в output/backups/landing-before-miniapp-2026-11-07.tar.gz соседнего проекта.

# Метапсихоанализ — публичная демоверсия

Статический лендинг будущего портала. HTML/CSS/JS, локальные шрифты и изображения; без базы, API, регистрации, cookies и аналитики. Telegram: https://t.me/metapsychoanalysis

Локальный запуск: `python3 -m http.server 8790 --bind 127.0.0.1`

GitHub Pages: публикация корня ветки main. Пользовательский домен metapsy.online подключается после проверки DNS и HTTPS. Не добавлять в этот репозиторий исходный backend, данные, PDF книги, секреты или конфигурацию CMS.

Демо-текст демонстрирует формат Front / Meta, не является цитатой из книги. Основной портал и редакция продолжают работать отдельно локально.

Шрифты Manrope: лицензия assets/fonts/OFL.txt. Визуал и знак перенесены из ранее подготовленного проекта портала.

# Метапсихоанализ — публичная демоверсия

Статический лендинг будущего портала. HTML/CSS/JS, локальные шрифты и изображения; без базы, API, регистрации, cookies и аналитики. Telegram: https://t.me/metapsychoanalysis

Локальный запуск: `python3 -m http.server 8790 --bind 127.0.0.1`

GitHub Pages: публикация корня ветки main, домен metapsy.online. Не добавлять в этот репозиторий исходный backend, приватные данные, секреты или конфигурацию CMS.

В каталоге `miniapp/` размещено отдельное приложение «Мета» с полной публичной читалкой книги «По ту сторону Фрейда». Полный текст, схемы и исходный PDF включены по поручению автора проекта. Закладки и заметки остаются в браузере читателя. Исходники приложения находятся в соседнем рабочем каталоге `vk-mini-app/`; сюда переносится только его проверенная сборка `dist/`. Обновление мини-приложения не меняет корневую страницу сайта.

Демо-текст демонстрирует формат Front / Meta, не является цитатой из книги. Основной портал и редакция продолжают работать отдельно локально.

Шрифты Manrope: лицензия assets/fonts/OFL.txt. Визуал и знак перенесены из ранее подготовленного проекта портала.
